# 蟹小箱 · XieBroToolBox

面向 Windows 用户的便携系统与文件管理工具箱。把电脑体检、空间清理、文件整理等常用功能放在一个应用里，让日常维护更直观、更方便。

**当前版本：1.2**

## 简介

- **免安装**：单文件便携版，打开即可使用，无需另行安装 .NET 运行时。
- **无需登录**：当前版本不启用账号和会员功能，本地工具可离线使用；网络检查需要网络连接。
- **统一界面**：多标签切换，支持浅色紫色与深色金色主题，可调整首页应用的显示和顺序。
- **按需操作**：先查看扫描结果和操作说明，再决定是否清理或修改文件。
- **关闭即退出**：不驻留托盘；有任务进行时先询问，确认后停止任务并退出。

## 现有功能

| 功能 | 说明 |
| --- | --- |
| 电脑体检 | 检查系统设备、存储状态、磁盘空间和网络，执行内存基础读写测试；提供屏幕、声音、键鼠、麦克风、摄像头与 USB 的功能验证，并支持导出报告。 |
| 垃圾清理 | 扫描临时文件、浏览器缓存、诊断文件等内容，查看明细并按需清理，支持排除目录。 |
| 系统盘瘦身 | 查看系统盘中可释放空间的项目与清理影响，提供 Windows 组件清理、旧系统清理、休眠文件管理等操作。 |
| 磁盘空间分析 | 按目录查看空间占用，通过列表或空间图找出大文件夹，逐层定位占用来源。 |
| 文件扫描 | 查找大文件、重复文件或指定类型的文件，支持扫描子目录；可自定义扩展名，与预设分类合并去重。 |
| 文件整理 | 按类型整理文件，提供批量重命名、修改预览、重名保护和撤销记录。 |
| 启动项管理 | 查看开机启动应用，按需关闭或恢复启动项。 |
| 软件卸载 | 查看和搜索已安装软件，调用软件自身的卸载程序。 |
| 硬件信息 | 查看硬件配置及可读取的温度、风扇转速等状态信息，支持导出报告。 |
| 网络检查 | 检查网络连接和网站访问情况，提供排查建议与报告。 |
| 内存释放 | 查看内存占用，按需整理内存，不通过结束应用进程来释放内存。 |

### 自定义文件类型

在“文件扫描 → 特定格式扫描 → 自定义文件类型”中输入扩展名，用空格分隔，例如：

```text
jpg png zip
```

自定义类型可以和上方分类同时选择。勾选“图片”并输入上述内容时，扫描条件为**图片分类 + zip**，重复扩展名会在扫描前合并。

### 体检与清理说明

电脑体检提供基础检查与用户功能验证，不替代完整内存测试、全盘坏块检测或专业硬件诊断。硬件信息的可用项目取决于设备与系统提供的数据。

清理前请查看对应项目的影响说明。删除旧系统文件可能影响系统回退，关闭休眠会影响相关功能；需要管理员权限的操作会请求授权。

## 从源码构建

使用 Windows 与 .NET SDK，SDK 版本以 [global.json](global.json) 为准（当前为 10.0.400）。桌面界面基于 WPF。

在项目根目录执行：

```powershell
dotnet restore XieBox.csproj
dotnet build XieBox.csproj -c Release --no-restore
```

打包 Windows x64 单文件便携版：

```powershell
.\scripts\Publish-Portable.ps1
```

默认输出到桌面的“蟹小箱发布”目录。当前桌面版无需部署后台服务即可使用；`backend/` 保留账号与管理服务代码，尚未在当前桌面版中启用。

## 项目结构

- `Views/`、`ViewModels/`：桌面界面与交互逻辑。
- `tools/`：各功能模块。
- `Platform.UI/`：共享界面组件。
- `Contracts/`、`Services/`：模块契约与平台服务。
- `Resources/`：主题、图标和第三方许可说明。
- `tests/`：功能与界面回归检查。
- `scripts/`：开发、打包和部署脚本。
- `backend/`：预留的账号与管理服务。
