# 平台动效规范

动效属于平台公共体验，模块复用 `Resources/Motion.xaml`，不各自定义一套速度和缓动。

- 按钮反馈 140 ms；页面和结果进入 260 ms；布局位置变化 440 ms，采用 EaseOut。
- 入口进入任务状态时立即反馈。标题、主操作等连续元素从原位置移动并缩放到新位置，其余内容淡入淡出，避免整个页面硬切。
- 扫描、安装等任务的进度留在任务标题与操作区域之间，不遮挡内容或抢占点击焦点。无法确定总量时使用不定进度，不显示虚假的百分比。
- 动效不延迟任务执行或清理确认；取消、失败和重复操作仍有明确状态。重复动画替换旧动画，避免队列累积。
- 遵循 Windows 客户端动画设置。关闭动画时直接展示最终布局，功能与状态一致。

当前已接入：平台页面切换、公共按钮按下反馈、垃圾清理首次扫描布局过渡、扫描结果进入。垃圾清理点击开始后即切到顶部任务布局，首次取消或失败后也保留该布局供重试；扫描结果和进度跟随真实任务状态。

## 统一弹窗

平台和子应用的自有弹窗继承 `Platform.UI/DialogWindow`，共用 `Dialogs.xaml` 的圆角边框、40 px 可拖动顶栏和右上角关闭按钮。登录弹窗的 `Title` 留空，其他弹窗设置具体标题；内容不再自行绘制顶栏或关闭按钮。主窗口仍保留自己的导航与托盘行为，系统文件夹选择器和回收站确认使用 Windows 原生界面。

打开时淡入 260 ms，关闭时淡出 140 ms。关闭按钮、Esc、Alt+F4 和业务完成后的 `Close()` 走同一生命周期；淡出期间阻止重复交互，结束后真正关闭并释放模态窗口。关闭系统动画时立即打开和关闭。清理和卸载确认使用 `DialogWindow.Confirm`，默认按钮为取消，仅点击确认后执行操作。
