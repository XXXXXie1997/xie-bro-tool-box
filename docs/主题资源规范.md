# 全局主题资源约定

## 资源分层

- `Resources/Palette.Light.xaml`：当前淡蓝主题的全部界面颜色。新增主题必须提供相同的资源键，值为 SolidColorBrush。
- `Resources/Theme.xaml`：公共控件模板、交互状态和基础样式。
- `Resources/Metrics.xaml`：公共字体、基础字号、控件/卡片/弹窗圆角。
- `Resources/Motion.xaml`：动效参数；`Resources/ScrollBars.xaml`：滚动条样式。
- `Services/ThemePalette.cs`：UI 线程调用 `Apply(ResourceDictionary)` 更换配色；先完整校验，再原位更新调色板键，使已打开控件同步刷新。

## 颜色用途

- 背景：CanvasBrush、SurfaceBrush、SoftBrush、TitleBarBrush、NavigationBrush。
- 文字与边框：InkBrush、MutedBrush、LineBrush、InputBorderBrush、TableLineBrush。
- 主题交互：AccentBrush、AccentInkBrush、AccentBorderBrush、HoverBrush、FocusBrush、RowHoverBrush、CardHoverBorderBrush。
- 选择与禁用：OnAccentBrush、CheckBorderBrush、ToggleOffBrush、DisabledBrush、DisabledInkBrush。
- 状态：SuccessBrush、WarningBrush、ErrorBrush、PendingBrush。
- 危险操作：DangerBrush、DangerBorderBrush、DangerSurfaceBrush。不能随主色替换为普通按钮颜色。

## 新增界面规则

XAML 颜色使用 DynamicResource。C# 创建控件用 SetResourceReference；FrameworkElementFactory 同样用 SetResourceReference。不要将 FindResource 得到的 Brush 固定赋值给长期存在的页面，也不要在 ViewModel 中构造具体颜色。

随状态变化的文字/边框，绑定 `ThemeResources.ForegroundKey` / `ThemeResources.BorderKey` 到语义资源名；状态变化和主题切换都能更新。

Logo、系统/软件图标以及 ApplicationIcon 的冻结默认图标作为图片资产保留原色；原生文件选择对话框与托盘菜单由 Windows 管理。布局尺寸、图标几何和透明度不属于配色，不应为了主题切换重写布局。

已提供稍深的淡蓝色与近黑深蓝色两套调色板，键必须保持一致。顶栏开关实时更新页面和弹窗。每次启动读取 Windows AppsUseLightTheme（应用颜色模式），无法读取时使用浅色。用户切换仅影响本次运行，不写入 appearance.json，也不修改系统设置；下次启动重新读取系统。菜单、提示、输入、选择与状态颜色均使用语义资源。

## 验证

主题测试覆盖已打开窗口、输入框、弹窗、状态文字和边框的换色，状态键切换、无效主题拒绝与恢复浅色。每次新增语义颜色时同步扩展调色板。





当前配色：浅色画布 #EEEEEE、内容块 #F5F5F5，深色画布 #222222，背景、文字及分隔线采用中性色；蓝色用于应用矢量图标、选中态及主要操作。PrimaryBrush / PrimaryHoverBrush / OnPrimaryBrush 独立控制实心主按钮，与轻量选中背景 AccentBrush 分开。ModuleIcon 统一首页、页签、应用管理与模块介绍的图标，不替换第三方软件图标。
