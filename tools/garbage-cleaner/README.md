# 垃圾清理 · 0.2 开发预览

业务、界面、规则和测试全部位于本目录。C# / WPF 独立工程，只依赖平台共享契约。免费、游客可用、离线运行，不连接账号 API 或上传路径。

首版流程：扫描 → 查看分类与清理影响 → 勾选类目或逐个文件 → 确认清理 → 查看成功、跳过和取消结果。主列表展示 6 个类目，各浏览器统一收在「浏览器缓存」，展开后可按浏览器选择，再进入文件明细逐项保留。分组汇总大小和数量，部分浏览器选中时显示半选；清理计划仍保留每款浏览器独立的运行状态检查。首次进入时居中显示标题、描述和「开始扫描」；点击开始即平滑过渡到顶部任务布局，在标题与「再次扫描」之间显示进度；扫描完成后淡入分类结果。扫描后全部不选，操作栏提供「全选」「取消全选」和已选类目数；全选包含所有可选类目，清理仍需确认。文件执行永久删除，清理前明确提示，不承诺恢复。

| 类目 | 当前范围 | 清理后果 |
| --- | --- | --- |
| 过期临时文件 | 当前用户 LocalAppData/Temp 中创建和修改均超过 7 天的 .tmp、.temp、.log | 对应临时资料、安装日志或恢复材料将永久丢失 |
| 崩溃转储 | LocalAppData/CrashDumps 中超过 7 天的 .dmp | 无法用这些文件分析当时的程序崩溃 |
| 错误报告 | 当前用户 WER/ReportArchive、ReportQueue 中超过 7 天的文件 | 诊断资料丢失，待发送报告不再发送 |
| 图形缓存 | LocalAppData/D3DSCache 中超过 1 天的文件 | 游戏和图形应用可能重新编译着色器，首次运行较慢或卡顿 |
| 浏览器网页缓存 | 识别出的标准配置缓存，分浏览器显示 | 网页需重新下载资源，首次打开可能变慢；保留密码、Cookie、历史、书签和用户下载 |
| 回收站 | Windows 查询当前用户所有本地磁盘回收站 | 无法再从回收站还原；独立选择，由 Windows 再次确认 |

浏览器适配规则包括 Chrome、Edge、360 安全浏览器、360 极速浏览器、QQ、夸克、搜狗和 Firefox。Chromium 类只匹配已知产品目录下带 Preferences 的 Default/Profile 配置，并要求 Cache/Cache_Data 的索引标记；Firefox 只匹配标准本地缓存和漫游配置对应的 cache2/entries。自定义安装位置、旧缓存格式和无法识别的布局不猜测清理；未发现目录会如实显示。正在运行的浏览器跳过扫描，执行前也重新检查。**这些是标准布局适配，尚未完成八款浏览器各版本的真实清理验收。**本机只读扫描识别到夸克缓存，Edge 因正在运行被跳过。

当前版本作为随平台编译分发的可信内置模块，平台安装按钮启用模块，安装过程无需联网；卸载移除启用清单，保留排除目录与结果摘要。模块 DLL 随平台一起更新，尚未实现独立下载或热更新原生模块。远程目录无法指定任意 DLL 或替换清理规则。源码仍独立在 tools 下，平台只负责入口、安装状态、上下文及任务协调。

安全边界：只扫描允许的目录，不进行全盘扩展名删除；不扫描桌面、下载、文档、聊天记录、网盘或系统组件。不跟随符号链接、目录联接或云端占位，不申请提权、不修改 ACL、不结束进程。扫描只查询元数据。执行计划冻结所选文件；逐文件固定父目录句柄、核对最终路径、卷及文件 ID、创建/修改时间、大小和硬链接数量，通过核验后的 Windows 句柄删除。不对缓存目录递归删目录。

回收站使用 SHQueryRecycleBin / SHEmptyRecycleBin 系统接口，不自行遍历或删除 $Recycle.Bin。执行前数量或大小变化会跳过；即使它们相同也不能证明集合未变化，因此说明执行时的系统确认范围可能包含扫描后移入的内容，不把回收站伪装成逐文件冻结计划。

扫描最多检查 250,000 个条目、保留 50,000 个候选文件，达到上限时禁用清理，要求添加排除目录后重扫。扫描结果超过 30 分钟也需重扫。取消后不发起新的文件删除，已完成操作保留结果；清理过的计划不能再次执行。任务中不能卸载模块，切换页面保留任务与结果。关闭窗口收起到托盘，任务继续；从托盘菜单退出时先请求取消并等待任务结束。

模块设置保存在平台数据目录 tools/garbage-cleaner 下：exclusions.json 是排除目录，last-result.json 只保存分类计数、时间及结果，不保存文件内容或完整路径。当前明细只在本次会话内显示，结果摘要不是备份。

构建后执行受控测试：

```powershell
dotnet tools/garbage-cleaner/tests/bin/Debug/net10.0-windows/XieBox.GarbageCleaner.Tests.dll
# 可选：只读扫描当前用户实际目录，不执行删除。
dotnet tools/garbage-cleaner/tests/bin/Debug/net10.0-windows/XieBox.GarbageCleaner.Tests.dll --scan-current-readonly
# 启动平台，安装并打开随平台提供的清理模块；不会自动扫描或清理。
.\scripts\Start-Dev.ps1 -OpenCleaner
```

57 项清理检查通过。破坏性测试全部限定在本项目 artifacts/cleaner-tests 的新建样本目录；回收站为模拟接口。已覆盖浏览器分组与部分选择、逐文件保留、排除、修改/替换、文件占用、硬链接、父目录联接替换、取消、计划重放、八款浏览器标准布局样本、运行中浏览器和界面渲染。尚需 Windows 10 测试机、高 DPI、真实浏览器配置清理前后对照和原生回收站交互验收。
