# 蟹小箱 · 垃圾清理 todoList

更新日期：2026-10-12

## 已确认范围

- 垃圾清理是独立子应用，代码、资源、规则、测试及构建配置放在本目录中。
- 模块全部免费，免注册、免登录，离线运行，首版不接入 AI。
- 复用平台统一用户上下文和授权接口；游客具有完整的免费清理能力，不创建独立账号、登录界面、用户数据库或支付鉴权系统。
- 首版覆盖当前用户临时文件、回收站、浏览器缓存，各类分别展示和选择。
- 开发顺序为只读扫描与可解释预览，然后加入经过验证的清理执行。
- 目标兼容 Windows 10 和 Windows 11；界面沿用平台的简约柔和风格。
- 浏览器适配目标包括 Chrome、Edge、360 安全浏览器、360 极速浏览器、QQ 浏览器、Firefox、夸克 PC 版、搜狗浏览器。
- 浏览器首版仅清理经过验证的缓存，保留密码、Cookie、浏览历史、书签及其他用户数据。
- 适配名单是开发目标，不代表当前已经支持；发布时只声明实际验证过的版本和范围。

## 当前交付

0.2 开发预览已接入平台：主列表 6 个分类（13 个内部规则类目），可见的清理后果、默认不选、类目和逐文件选择、排除目录、永久删除确认、结果明细。各浏览器合并为「浏览器缓存」，展开后分别选择，部分选择显示半选。57 项清理检查通过。首次进入显示居中的标题、说明与「开始扫描」；点击开始即动画过渡到顶部布局，中间显示扫描进度，完成后淡入结果；提供全选、取消全选、已选类目数与「再次扫描」。浏览器标准布局适配和受控样本已实现，以下各浏览器条目保留未完成，待真实版本清理前后验收。完整行为与边界见 [README](README.md)，官方资料见 [调研记录](rules/research.md)。

- [x] 为每类规则记录允许扫描的根目录、目标类型、时间条件、排除项、关闭应用要求、删除方式和可能影响。
- [x] 使用系统路径查询与配置识别实际目录，避免硬编码用户名、盘符和浏览器版本目录。

- [x] 确定回收站扫描和清空的系统接口及权限边界，单独说明清空后无法从回收站恢复。

## 3. 只读扫描与预览

- [x] 展示当前用户数据盘可用空间、分类规则范围和扫描候选大小。
- [ ] 补充多磁盘总容量与分盘实际占用展示。
- [x] 扫描在后台执行，支持取消，权限错误和局部失败不导致整个模块崩溃。
- [x] 展示临时文件、回收站、各浏览器缓存的分类大小、路径、原因及可能影响。
- [x] 区分候选逻辑大小、成功删除的逻辑大小和实测可用空间变化，不将扫描估算标记为已释放空间。
- [ ] 补充稀疏/压缩文件的实际磁盘占用统计。
- [x] 支持查看具体候选项、选择清理范围、排除目录并保存排除设置。
- [x] 回收站作为独立选择项，不默认与普通缓存一同选中。
- [x] 扫描阶段不删除、不下载云端占位文件、不修改权限或系统配置。
- [x] 处理符号链接、目录联接、挂载点、云端占位文件和网络路径，默认跳过无法安全判定的对象。

## 4. 清理计划与执行

- [x] 根据用户选择生成明确的清理计划，展示执行范围、删除方式和预计候选大小。
- [x] 用户确认后冻结计划；扫描器、计划生成与执行器分离。
- [x] 执行前重新核验规则、路径边界、文件身份、修改状态及父级目录，条件变化时跳过。
- [x] 通过合适的 Windows 文件句柄和路径校验策略降低扫描到执行之间的竞态风险。
- [x] 对每条规则明确永久删除、回收站或其他方式的语义，不声称同盘回收站/隔离区立即释放空间。
- [x] 回收站清空使用独立确认，明确无法通过回收站找回。
- [x] 文件占用和权限不足时跳过，不强杀进程、不修改 ACL、不抢占所有权。
- [x] 用户取消后不发起新删除，准确保存已发生的操作结果。
- [x] 防止计划重复执行；应用异常退出后不自动继续删除。
- [x] 记录成功、失败、跳过、取消和未知状态，不将部分完成显示为全部成功。

## 首版不包含

- 注册表清理、驱动处理、系统服务优化和软件安装路径迁移。
- 自动清理桌面、下载、文档、照片、聊天记录及网盘文件。
- 直接删除 Windows、WinSxS、Installer、Program Files 等关键目录内容。
- 自动结束进程、无人值守自动清理和未经确认的删除。

以上边界用于本轮实现；新增清理类别时需补充独立规则和测试，不通过扩大目录通配范围实现。

详情文件勾选与外层类目双向联动：零选为未选、部分为半选、全部为全选；点击半选类目补选全部文件，取消类目则清空文件选择。浏览器子类目和总分组同步聚合，已选数量、大小和清理计划使用同一份选择状态。
