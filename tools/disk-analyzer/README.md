# 磁盘空间分析

离线、只读的目录大小分析工具，入口由平台管理，使用平台 scan 免费能力。

- 选择磁盘根目录或普通目录，递归汇总文件逻辑大小。
- 当前层级按大小降序展示，显示占比，可逐层进入、返回、打开资源管理器位置。
- 支持停止，保留部分结果；权限不足、链接和离线项目跳过并明确提示。
- 最大检查 200,000 项，达到上限提示缩小范围；后台扫描，进度每 100ms 节流。
- 统计为扫描时快照。硬链接按路径计入，不等于物理磁盘占用或可释放空间；没有删除或自动判断可清理功能。
- 使用平台主题、虚拟化表格、细滚动条、页面过渡、统一提示弹窗与任务退出取消机制。

源码：src。测试：tests/DiskAnalyzer.cs（平台测试项目）。
