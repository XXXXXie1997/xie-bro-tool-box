# 电脑体检

- [x] 首页最上方内置体检区，不注册为可安装应用；复用已有应用的只读检测能力
- [x] 检查本地磁盘剩余空间、内存、启动项、网络和可清理文件
- [x] 分项进度、取消、单项时间预算和失败隔离
- [x] 建议处理 / 检查正常 / 未完成分组，不做健康评分
- [x] 结果跳转子应用，已打开页签复用并保留原状态；体检本身不创建页签
- [x] 新打开的清理、启动项、网络页面复用体检快照
- [x] 磁盘入口带入盘符；内存入口显示实时数据
- [x] 清理保留原引擎的快照验证、排除目录和二次确认
- [x] 体检报告包含结果与网络技术记录，不自动上传
- [x] 取消、部分失败、快照交接和返回页面回归验证

默认不扫描整盘文件、不比较重复内容、不自动清理、释放内存或修改启动项。每个检测项目使用 20 秒取消预算，超时项目允许进入对应应用继续检查。磁盘不足 10%、内存占用达到 85% 为处理建议，不等同硬件故障。已打开的子应用不会被体检结果覆盖。
