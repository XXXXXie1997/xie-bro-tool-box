# 文件操作共用引擎

重命名与文件整理共用预览、文件指纹、目标冲突检查、写前日志和撤销。执行时持有文件及祖先目录句柄，拒绝并发写入和路径链接，不覆盖目标。

## 当前边界

最大 5,000 个普通文件；校验读取文件内容。操作记录存于平台用户数据目录，卸载模块不删除操作记录。只保留当前批次一键撤销，结束批次后历史记录归档。

## 接入与验证

- 源码独立放在 src。应用复用平台身份与免费能力接口。
- 页面复用 Platform.UI/ToolPage.cs、全局主题、虚拟化表格、滚动条和动效。
- 文件操作测试只使用隔离目录；不在用户机器上执行真实卸载或网络修复来测试。
- 回归测试见 tests/ExpandedTools.cs。
