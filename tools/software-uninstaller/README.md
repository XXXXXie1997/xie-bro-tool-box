# 软件卸载

读取 HKCU/HKLM 的 32/64 位卸载注册信息，支持搜索。确认后调用原卸载程序；MSI 使用产品 GUID。拒绝不明确或脚本解释器命令，提供系统应用设置入口。

## 当前边界

商店应用与部分非标准卸载程序通过系统设置处理；不扫描或删除软件残留。

## 接入与验证

- 源码独立放在 src。应用复用平台身份与免费能力接口。
- 页面复用 Platform.UI/ToolPage.cs、全局主题、虚拟化表格、滚动条和动效。
- 文件操作测试只使用隔离目录；不在用户机器上执行真实卸载或网络修复来测试。
- 回归测试见 tests/ExpandedTools.cs。
