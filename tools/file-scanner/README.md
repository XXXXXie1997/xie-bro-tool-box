# 文件扫描

独立 WPF 子应用，目录 `tools/file-scanner`。由平台内置模块白名单注册，使用平台传入的 `IPlatformContext` 校验扫描能力，支持游客离线扫描。安装、卸载、首页入口和导航复用平台。

## 初版能力

- 选择或输入一个目录，包含子目录；只读取元数据，不删除、移动或打开文件内容。
- 大文件：默认超过 100 MB，最低 50 MB，整数输入；1 MB 按 1024 × 1024 字节计算，等于阈值不匹配。
- 格式集：视频、音频、图片、压缩包，可多选。扩展名不区分大小写，具体集合见 `ScanEngine.Formats`，界面悬停可查看。
- 后台遍历，最多每 100ms 报告扫描数量；未知总量时使用不定进度，支持停止并保留部分结果。
- 结果默认按数值大小降序；支持点击表头排序、查看完整路径及在资源管理器定位文件。
- 共用平台表格、复选框、平滑滚动与入场动效；结果保留在内存，切换应用不丢失。

## 扫描边界

跳过目录链接、文件链接、离线文件以及无权限或已消失的项目。最多检查 500,000 项、保留 50,000 个匹配结果，达到限制会提示缩小范围，不冒充完整结果。检查文件扩展名，不推断真实媒体内容。网络目录受系统 I/O 响应影响，停止会在当前枚举调用返回后生效。

## 验证

平台测试中使用独立测试目录验证阈值、大小排序、子目录、大小写匹配、取消、只读行为、游客扫描、条件保留及安装卸载。预览图输出至 `artifacts/previews/scanner-*.png`。

预览启动：`scripts/Start-Dev.ps1 -OpenScanner`，只打开应用，不自动扫描用户目录。
